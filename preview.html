PLUGIN GUIDE / FIGMA

웹 화면을 가져와
Figma에서 편집하세요.

파일이나 코드, 공개 웹페이지 주소를 준비하세요. 미리보기에서 화면을 확인한 뒤 Figma에 편집 가능한 레이어로 삽입합니다.

파일·코드·URL 가져오기 렌더링 미리보기 Figma 레이어 삽입
01 시작하기 02 소스 입력 03 렌더링 확인 04 Figma 삽입 05 사용 팁

01먼저, 가져올 소스를 선택하세요

  1. 플러그인 상단에서 준비한 소스에 맞는 탭을 선택합니다. 파일은 File, 코드는 Edit, 공개 웹페이지 주소는 Link를 사용합니다.
  2. 선택한 탭에서 파일을 올리거나 코드를 붙여넣거나 URL을 불러옵니다.
  3. Width에서 미리보기 너비를 설정하고 렌더링 확인을 눌러 가져올 화면을 확인합니다.

화면을 확인한 뒤 Figma에 삽입합니다. 삽입 버튼이 비활성 상태라면 렌더링 확인을 눌렀는지 살펴보세요. 미리보기에서 ‘렌더링 확인 완료 · Figma 삽입 가능’이 표시되면 삽입할 수 있습니다.

02준비한 소스에 맞는 탭을 선택하세요

File에서 파일 가져오기

파일 선택을 눌러 HTML, CSS, JS, JSON과 이미지를 선택합니다. HTML에 상대 경로로 지정된 이미지는 업로드한 파일명으로 연결됩니다. 대체 이미지가 필요하면 클립보드 이미지 가져오기를 누릅니다.

Edit에서 코드 붙여넣기

HTML · CSS · JS · JSON 중 해당 탭에 코드를 붙여넣습니다. 렌더링할 때 JS가 실행됩니다. JS에서 JSON 데이터가 필요하면 window.pageData 또는 window.jsonData를 사용합니다.

Link에서 공개 웹페이지 가져오기

WEBPAGE URL에 주소를 입력하고 URL 불러오기를 누릅니다. HTML과 JSON을 제공하는 서버가 CORS 접근을 허용해야 합니다. 로그인 페이지나 복잡한 SPA는 재현이 제한될 수 있습니다.

파일 입력 예시 index.html + style.css → File

HTML·CSS 예제로 연습하기

  1. HTML 복사를 누르고 UI 체험의 Edit → HTML에 붙여넣습니다.
  2. CSS 복사를 누르고 Edit → CSS에 붙여넣습니다.
  3. 렌더링 확인을 눌러 파란 제목과 연한 파란색 배경이 있는 카드가 표시되는지 확인합니다.
HTML
<main class="sample-card">
  <h1>Hello Figma</h1>
  <p>첫 번째 디자인을 가져와 보세요.</p>
</main>
CSS
.sample-card {
  max-width: 420px;
  margin: 32px auto;
  padding: 24px;
  border-radius: 12px;
  background: #eef6ff;
}
.sample-card h1 { color: #0876c9; }

03화면 크기를 설정하고 미리 보세요

Width
미리보기 너비를 100–3000px 범위에서 설정합니다. 기본값은 1440px입니다.
Height
렌더링한 HTML의 전체 높이가 자동으로 표시됩니다.
배경 포함
배경과 도형, 이미지도 가져오려면 배경 · 도형 · 이미지 레이어 포함을 선택합니다.
  1. 렌더링 확인을 눌러 미리보기를 엽니다.
  2. 미리보기에서 글꼴과 이미지, 스크립트로 불러온 데이터가 표시되는지 확인합니다.
  3. 미리보기 아래에서 생성 예정 프레임과 하위 레이어 수를 확인합니다.

04확인한 화면을 Figma에 삽입하세요

  1. 렌더링을 확인한 뒤 Figma Desktop에서 Figma에 삽입을 누릅니다.
  2. 화면이 6,000px보다 길면 다음 영역 Figma에 삽입을 눌러 나머지를 가져옵니다.
  3. Figma 캔버스에서 생성된 프레임과 레이어를 확인합니다.

가져온 화면은 레이어 단위로 편집합니다. 클릭이나 페이지 이동을 추가하려면 Figma에서 별도로 설정하세요.

자주 묻는 질문

이 페이지에서 Figma 파일도 바뀌나요?

브라우저의 UI 체험에서는 렌더링 결과와 삽입 요청 기록을 확인할 수 있습니다. 실제 레이어를 추가하려면 Figma Desktop에서 플러그인을 실행하고 Figma에 삽입을 누르세요.

Figma에 삽입 버튼은 언제 활성화되나요?

렌더링 확인을 누르고 미리보기 로딩이 끝날 때까지 기다리세요. 로딩이 길어지면 미리보기 아래의 상태 메시지를 확인하세요.

이미지가 표시되지 않으면 어떻게 하나요?

먼저 이미지 주소와 접근 권한을 확인하세요. 이미지 파일이 있다면 File 탭에 추가하거나 클립보드 이미지 가져오기를 사용하세요. 파일 하나당 이미지는 8MB, 코드는 1MB까지 가져올 수 있습니다.

원본과 글꼴이나 레이아웃이 왜 다른가요?

원본 글꼴이 Figma에서 사용 가능한지 확인하세요. 여러 배경이나 복잡한 Flex/Grid 배치는 삽입한 레이어를 확인한 뒤 캔버스에서 조정하세요.
