기능 사용 안내

시작하기

  • Figma 디자인 파일에서 HTML to Figma 플러그인을 실행합니다. 가져올 소스에 맞춰 File, Edit, Link 중 하나를 선택합니다.

File · 파일 가져오기

  • 파일 선택에서 HTML, CSS, JS, JSON과 이미지를 선택합니다.
  • 대체 이미지는 클립보드 이미지 가져오기로 추가합니다.

Edit · 코드 직접 입력

  • HTML·CSS·JS·JSON 탭에 해당 코드를 입력합니다.
  • 입력한 JS는 렌더링할 때 자동 실행됩니다.

Link · 웹페이지 불러오기

  • WEBPAGE URL에 주소를 입력하고 URL 불러오기를 누릅니다.
  • CORS 접근을 허용하는 공개 페이지를 가져올 수 있습니다.

공통 · 설정, 렌더링 및 삽입

  • Width로 너비를 설정합니다. Height는 자동 계산됩니다.
  • 필요하면 배경 · 도형 · 이미지 레이어 포함을 선택합니다.
  • 렌더링 확인에서 화면과 레이어를 확인합니다. 준비되면 Figma에 삽입을 누릅니다.
  • 높이가 6,000px을 넘으면 다음 영역 Figma에 삽입을 누릅니다.

키보드 접근성

  • Tab·Shift+Tab으로 항목을 이동합니다. Enter·Space로 버튼을 실행합니다.
  • 입력 모드와 소스 파일 탭은 ←·→로 전환합니다. Home·End로 첫 탭과 마지막 탭에 이동합니다.
  • WEBPAGE URL에 주소를 입력하고 Enter를 누릅니다.
  • 도움말 본문에 초점을 둔 뒤 ↑·↓로 스크롤합니다. Esc로 닫으면 도움말 버튼으로 초점이 돌아갑니다.
